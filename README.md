# RockLex Studio

**RockLex Studio** —— 一款面向 Minecraft 基岩版的现代化插件、脚本与资源包编辑器，基于 Electron \+ Vue3 \+ TypeScript 构建，主打轻量化、高效、可视化开发体验。

## ✨ 项目介绍

基岩版插件开发手动改文件、工具零散，效率低、易出错。**RockLex Studio** 整合全套开发流程，一站式完成脚本编写、JSON配置、项目管理、文件预览、一键部署，专为 MCBE 创作者与开发者设计。
